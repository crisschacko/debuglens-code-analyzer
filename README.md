# DebugLens

An AI-inspired code debugging assistant that analyzes code and error messages to identify common programming issues and provide clear debugging suggestions.

## Features

- Code analysis
- Error message analysis
- Common error detection
- Simple debugging suggestions
- Responsive web interface
- Flask-based backend

## How It Works

1. User enters source code.
2. User optionally provides an error message.
3. DebugLens analyzes the input.
4. Common issues are identified.
5. Debugging suggestions are displayed.

## Technologies

- Python
- Flask
- HTML
- CSS
- Regular Expressions
